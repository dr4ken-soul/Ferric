## Ownership

`schema.py` owns validated domain models and cross-module enums. It contains no provider logic or file access.

`store.py` owns cassette and manifest persistence, stable content hashes, listing and deletion consistency. It accepts validated models and does not redact data itself.

`redact.py` owns built-in and user-declared secret rules. The store write path calls it before serialisation.

`adapters/` owns provider-specific request and response normalisation. Adapters import provider SDKs lazily and return the shared event schema.

`wrapper.py` owns the one-line public integration and runtime mode selection. `matcher.py` owns fingerprints, exact lookup and nearest-cassette diagnostics.

`assertions.py` owns behavioural comparisons and actionable failure messages. `cli.py` coordinates commands but delegates storage, redaction, matching, assertion and report work.

`report.py` owns the self-contained drift report template. It must not depend on the Vite application.

## Data Flow

Record flow:

```text
application -> wrapped client -> provider -> adapter -> redactor -> store
```

Replay flow:

```text
application -> wrapped client -> fingerprint -> matcher -> store -> recorded response
```

Drift flow:

```text
CLI -> cassette library -> target provider -> normaliser -> classifier -> HTML report
```

Replay has no provider edge. An unmatched fingerprint raises with the full fingerprint and nearest cassette. It never invokes record or passthrough behaviour.

## Test Placement

- Unit and integration tests that run offline live directly under `tests/`.
- Real stripped provider payloads and expected normalised output live under `tests/goldens/`.
- Redacted replay cassettes live under `tests/cassettes/`.
- Tests that intentionally import a network or provider package live only under `tests/drift/` and are excluded from the default pytest target.
- The demo fixture under `examples/demo-agent/` uses committed cassettes and no key.

## Web Placement

Shared visual primitives belong in `web/src/components/ui/`. Nav and footer belong in `layout/`. The eight landing sections belong in `sections/`. Hooks contain reusable browser behaviour, not presentation. Generated cassette data lives at `web/src/data/cassettes.generated.ts` and is never edited by hand. Repository and demo URLs live in `web/src/config.ts`.

The landing page follows the exact section order in `FRONTEND_SPEC.md`. The docs route uses the same Vite app. The HTML drift viewer remains generated by Python because it must open from the filesystem without the web bundle.

## Change Discipline

Keep provider conditionals inside adapters. Keep command orchestration out of domain models. Add shared abstractions only when two real call paths need them. A feature is complete only when its mapped acceptance criteria have automated evidence and the task entry can name that evidence.
